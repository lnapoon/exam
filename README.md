# ระบบสรุปเนื้อหา แผนภาพประกอบ และคลังข้อสอบ การสื่อสารข้อมูลและเครือข่าย

เว็บแอปพลิเคชันสำหรับทบทวนเนื้อหาและฝึกทำข้อสอบวิชาการสื่อสารข้อมูลและเครือข่ายคอมพิวเตอร์ ครอบคลุม **บทที่ 1, 2, 5, 7, 8 และ 10**

## ฟีเจอร์หลัก
- **คลังข้อสอบทั้งหมด 260 ข้อ**:
  - ข้อสอบรายบท (บทที่ 1, 2, 5, 7, 8, 10) บทละ **30 ข้อ** (รวม 180 ข้อ)
  - ข้อสอบรวมทุกบท จำนวน **80 ข้อ** พร้อมตารางวิเคราะห์คะแนนแยกรายบท
  - รองรับทั้ง **โหมดฝึกฝน (เฉลยทันที)** และ **โหมดสอบจริง (ส่งกระดาษคำตอบทีเดียว)**
- **สรุปเนื้อหาโดยละเอียด & จุดเน้นต้องจำพิเศษ** ครบทั้ง 6 บทเรียงตามลำดับ
- **แผนภาพสีประกอบความเข้าใจ 50 ภาพ** วางแทรกตรงเนื้อหาแต่ละหัวข้อ (ครบทุก "รูปที่ X.Y" และ "ตัวอย่างที่..." ในตำรา) พร้อมแท็บคลังแผนภาพสรุป
- รองรับ **โหมดสว่าง / โหมดมืด**, ค้นหาคำสำคัญ, สุ่มลำดับข้อสอบ และบันทึกความคืบหน้าอัตโนมัติผ่าน `localStorage`
